## 原始材料与整理改动

本项目从课程目录“实验课”整理。`src/` 以该目录顶层 MATLAB 文件为来源，`tests/test_weight_search.m` 为已有的小网格测试。原实验文件未被改写。

本次整理对运行行为的调整：

1. 恢复 `gs_demo.m` 和 `gs_image_demo.m` 原来被整段注释的保存代码。
2. 使用 `make_result_dir`，每次运行都在仓库 `results/` 下建立独立目录，避免原来随机写入当前目录或覆盖随机编码结果。
3. 修正固定加权双平面代码中一条误写为“等权”的注释，数值更新公式不变。
4. 添加输出目录测试和短迭代导出检查，保留原来的权重优化测试。

原报告中的旧目录名和“源代码文件夹”指整理前的材料。现在代码统一在 `../src/`；报告描述的历史 CSV 和代表性图片在 `../examples/`。大型 MAT 留在原实验目录，不包含在 Git 中。

## 相位 PNG 的适用范围

二维 GS 直接在 1080×1920 网格计算；深度 GS 在 1536×2560 网格计算后中心裁取 1080×1920，不对相位插值。它们按 `uint8((phase+pi)/(2*pi)*255)` 进行理想线性编码，并在写出后检查尺寸、位深与像素读回。

随机编码的相位按 [0,2π) 编码，只输出 512×512 有效区，不能直接当作 Full-HD 设备加载文件。其照明孔径也与深度 GS 不同。

实际加载还需确认工作波长、灰度到相位的 LUT、照明范围、偏振、传播距离与像素一一映射。外围零相位不会挡光；`illumination_reference_only.png` 仅为照明示意。历史深度仿真 633 nm，报告记载现场 532 nm，不能直接把仿真设计距离当作现场实测距离。

## 检查方法

从仓库根目录运行：

```matlab
addpath('src', 'tests');
test_weight_search;
test_result_dir;
test_demo_exports;
```

- 权重测试：评分尺度不变性、零填充不变性、固定随机起点、输入振幅约束、最终评分与选中光场一致。
- 输出路径测试：不同运行目录、限定在 `results/` 内、拒绝路径穿越名称。
- 导出测试：直接读取 5 个演示脚本，在内存副本中将迭代预算缩为 2 次；保留完整画布、保存和读回代码。图片入口使用自动生成的灰度渐变测试图代替手动选择。源文件和默认迭代预算不变。

短迭代检查验证运行与导出流程，不用于判断收敛质量。随机编码完整对照和完整权重搜索应按各自默认入口另行运行。
